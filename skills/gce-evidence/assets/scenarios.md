# GCE evidence skill scenario fixtures

These are **synthetic prompts and observations**, with expected behavior for later review/evaluation, not executed agent traces or proof of agent reliability. In each case, retain only authorized technical evidence; no fixture authorizes file access, installation, delivery decisions, or release operations. Apply the [skill](../SKILL.md), [consumer workflow](../references/consumer-workflow.md), and [skill specification](../../../openspec/changes/post-preview-agent-skill-published-preview/specs/gce-evidence-agent-skill/spec.md). Required/forbidden columns describe expectations, not observed outcomes.

## Review boundary

Check each row's route, required observation, forbidden behavior, and linked existing contract against the specification. Static fixture review is not an agent run; only a later evaluation with the skill actually loaded, retained prompts/model/runtime/revision/tool trace/outputs/deviations can establish observed agent behavior. Existing Go tests, if run separately, anchor executable contracts rather than this skill's adherence. Multilingual census remains a separate post-preview roadmap, not an implicit scenario implementation.
